# OCR准确率测试系统使用说明

## 系统概述

已成功创建了一个完整的OCR准确率测试系统，包含以下功能：

- ✅ 多语言OCR测试（中文、英文、日文、韩文、泰文、俄文、阿拉伯文、印地文）
- ✅ 自动生成测试图片（24张，8种语言，每种3张不同复杂度）
- ✅ API测试脚本，支持批量测试
- ✅ 准确率分析工具，计算多种指标
- ✅ 可视化报告生成器
- ✅ 一键测试脚本

## 快速开始

### 1. 启动OCR API服务

```bash
cd /root/lhy/paddleocr
python main.py
```

### 2. 运行测试

#### 方法一：一键测试（推荐）

```bash
cd /root/lhy/paddleocr/accuracy_test
./start_test.sh
```

#### 方法二：手动运行

```bash
cd /root/lhy/paddleocr/accuracy_test
python3 run_test.py
```

### 3. 查看结果

测试完成后，查看以下目录：

- `results/` - 测试结果JSON文件
- `reports/` - HTML报告和图表
- `test_images/` - 生成的测试图片

## 测试内容

### 支持的语言

1. **中文 (zh)** - 3张测试图片
2. **英文 (en)** - 3张测试图片  
3. **日文 (ja)** - 3张测试图片
4. **韩文 (ko)** - 3张测试图片
5. **泰文 (th)** - 3张测试图片
6. **俄文 (ru)** - 3张测试图片
7. **阿拉伯文 (ar)** - 3张测试图片
8. **印地文 (hi)** - 3张测试图片

### 测试指标

- **成功率**: 测试图片成功识别的比例
- **精确率**: 识别结果中正确文本的比例
- **召回率**: 期望文本中被正确识别的比例
- **F1分数**: 精确率和召回率的调和平均数
- **精确匹配**: 完全匹配期望文本的比例
- **字符准确率**: 字符级别的识别准确率
- **处理时间**: 单张图片的平均处理时间

## 文件说明

### 核心脚本

- `run_test.py` - 主测试脚本，一键运行完整测试
- `test_api.py` - API测试脚本，执行OCR识别测试
- `analyze_results.py` - 结果分析工具
- `generate_report.py` - 报告生成器
- `prepare_test_images.py` - 测试图片生成器

### 配置文件

- `test_config.json` - 测试配置，包含各语言的测试图片和期望结果
- `start_test.sh` - 一键启动脚本

### 输出目录

- `test_images/` - 生成的测试图片（24张）
- `results/` - 测试结果JSON文件
- `reports/` - HTML报告和性能图表

## 使用示例

### 1. 完整测试流程

```bash
# 启动API服务（在另一个终端）
cd /root/lhy/paddleocr
python main.py

# 运行测试
cd /root/lhy/paddleocr/accuracy_test
./start_test.sh
```

### 2. 分步测试

```bash
# 1. 准备测试图片
python3 prepare_test_images.py --update-config

# 2. 运行API测试
python3 test_api.py --api-url http://localhost:16110 --config test_config.json

# 3. 生成报告
python3 generate_report.py results/ocr_test_results_*.json
```

### 3. 自定义测试

编辑 `test_config.json` 文件来添加自定义测试图片：

```json
{
  "zh": {
    "images": ["/path/to/your/chinese_test.jpg"],
    "expected_texts": {
      "/path/to/your/chinese_test.jpg": ["期望识别的文本1", "期望识别的文本2"]
    },
    "score_threshold": 0.5
  }
}
```

## 报告内容

生成的测试报告包含：

1. **测试概览** - 总体统计信息
2. **语言性能排名** - 各语言按性能排序
3. **详细语言分析** - 每种语言的详细指标
4. **性能图表** - 可视化性能对比
5. **改进建议** - 基于测试结果的优化建议

## 注意事项

1. **API服务**: 确保OCR API服务正在运行（默认端口16110）
2. **依赖包**: 系统会自动检查并安装必要的Python包
3. **权限**: 确保有写入权限创建测试图片和报告
4. **网络**: 确保API服务可访问
